# План приложения заметок «Заметки» (команда Test1, роль: Планировщик)

Исходный запрос: «Создай приложение заметок, много функций, красивый интерфейс».

## 1. Выбор стека

Учитывая, что в `/root/notes-app` уже есть заготовка проекта, стек фиксируем на ней — это минимизирует риск и ускоряет разработку.

| Слой | Технология | Обоснование |
|---|---|---|
| UI | React 18 + TypeScript | уже установлен, типизация моделей данных |
| Сборка | Vite 8 + vite-plugin-singlefile | одна HTML-файл сборка → открывается офлайн в WebView Android без сервера |
| Состояние | Zustand 5 | лёгкий, подходит для глобального стора заметок/настроек |
| Персистентность | idb-keyval (IndexedDB) | офлайн-хранение без БД и без localStorage-лимита 5 МБ |
| Иконки | lucide-react | единый набор иконок, уже в зависимостях |
| Валидация | zod | проверка схемы заметки при импорте/экспорте |
| Стили | index.css + CSS-переменные + `prefers-color-scheme` | без Tailwind, чтобы не тянуть рантайм-CSS в single-file |
| Шрифт | Inter (Google Fonts, с офлайн-фолбэком на system-ui) | уже подключён в index.html |

Почему не React Native/Expo: целевая среда — Android WebView-превью OpenCode Mobile, single-file сборка даёт готовый результат без Gradle-сборки. Миграция возможна позже, т.к. логика вынесена в `src/store.ts` и `src/lib/*` (чистый TS, без привязки к DOM-рендеру).

## 3. Структура экранов

Мобильный-first, одна страница-приложение с переключением видов (без роутера как такового, состояние экрана в Zustand).

```
┌─ App
│  ├─ AppShell (header + layout)
│  │   ├─ Header: логотип, поиск, кнопки: тема, меню (⋯)
│  │   ├─ Sidebar (drawer, слева, на моб. — выезжает)
│  │   │   ├─ Навигация: Все / Избранное / Архив / Корзина
│  │   │   ├─ Папки (список, +, переименование, цвет)
│  │   │   ├─ Теги (чипы, фильтр)
│  │   │   └─ Футер: переключатель темы, Импорт/Экспорт
│  │   └─ NotesView
│  │       ├─ Toolbar: сортировка, layout-переключатель, счётчик
│  │       └─ NotesGrid / NotesList → NoteCard
│  ├─ EditorModal (полноэкранный на моб., 2 колонки на десктопе)
│  │   ├─ Заголовок (input), тело (textarea, авто-высота)
│  │   ├─ Панель свойств: папка, теги, цвет, закрепление, избранное
│  │   └─ Footer: статус сохранения, дата, кнопки Экспорт/Удалить
│  ├─ SettingsModal: тема, layout, автосохранение (интервал), экспорт/импорт
│  ├─ ConfirmDialog: удаление, очистка корзины, импорт
│  └─ Toast: Undo, «Экспортировано», ошибки
```

Маршруты (для будущей навигации): `#/notes`, `#/notes/:id`, `#/favorites`, `#/archive`, `#/trash`, `#/settings`.

## 4. Модель данных

```ts
interface Note {
  id: string;              // crypto.randomUUID()
  title: string;
  content: string;         // markdown-lite / plain text
  createdAt: number;       // epoch ms
  updatedAt: number;
  color: NoteColor;
  folderId: string | null;
  tags: string[];          // нормализованные, без '#'
  pinned: boolean;
  favorite: boolean;
  archived: boolean;
  deletedAt: number | null; // null = не в корзине
}

interface Folder {
  id: string;
  name: string;
  color: string;
  createdAt: number;
}

interface Settings {
  theme: 'light' | 'dark' | 'system';
  layout: 'grid' | 'list';
  sortBy: 'updatedAt' | 'createdAt' | 'title';
  sortDir: 'asc' | 'desc';
  autosaveDelayMs: number;  // 500
}

interface DB {
  notes: Note[];
  folders: Folder[];
  settings: Settings;
}
```

Индексы в IndexedDB (`idb-keyval`): отдельные ключи `notes`, `folders`, `settings`. Индексы по `updatedAt`, `folderId`, `tags` строятся в памяти (объём мал, <10k записей).

Инварианты:
- `deletedAt != null` ⇔ заметка в корзине и скрыта из основных списков.
- Теги автоматически извлекаются из текста (`/#[\p{L}\p{N}_-]+/gu`) и объединяются с ручными.
- Удаление папки не удаляет заметки — они переходят в «Без папки».

## 7. Критерии готовности (Definition of Done)

- [ ] Создание/редактирование/удаление работают и переживают перезапуск страницы
- [ ] Папки и теги фильтруют список, счётчики совпадают с фактом
- [ ] Поиск находит по заголовку и содержимому мгновенно, есть подсветка
- [ ] Избранное и закрепление отражаются в списке и в разделах
- [ ] Переключение темы мгновенное и сохраняется
- [ ] Экспорт в JSON/Markdown/TXT даёт валидный файл, импорт JSON восстанавливает данные
- [ ] Автосохранение не теряет правку (< 1 с после паузы)
- [ ] Адаптив: 360 px и 1280 px без горизонтальной прокрутки
- [ ] Сборка `npm run build` → один HTML-файл, открывается офлайн
